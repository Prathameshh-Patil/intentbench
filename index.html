IntentBench

A fine-tuned DistilBERT that sorts a message into one of 150 intents, or says it is out of scope. It runs in your browser, so nothing you type leaves this page.

Loading the model (about 70 MB, cached after the first visit) ...

Trained on CLINC150. Scores are from the held-out test set (5,500 queries), full-precision model with the same threshold; this page runs an int8 copy. Code, the TF-IDF baseline and the LLM comparison: github.com/Prathameshh-Patil/intentbench.
